🔗 Connexion Notion
Connectez une base de données Notion pour sauvegarder vos jeux dans le cloud et y accéder depuis n'importe quel appareil.
1. Créez une intégration sur notion.so/my-integrations
2. Copiez le token de l'intégration ci-dessous
3. Partagez votre base de données avec l'intégration
