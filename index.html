🔗 Connexion Notion
Connectez une base de données Notion pour sauvegarder vos jeux dans le cloud et y accéder depuis n'importe quel appareil.
1. Créez une intégration sur notion.so/my-integrations
2. Copiez le token de l'intégration ci-dessous
3. Partagez votre base de données avec l'intégration
4. Copiez l'ID de la base (32 caractères dans l'URL)
🗂 Correspondance des champs Notion

Entrez le nom exact de chaque propriété dans votre base Notion (respectez la casse et les accents).

Valeurs attendues pour Propriétaire : J (Joueur 1), M (Joueur 2), FR (Familles Rurales)
En multi-sélection, un jeu peut avoir plusieurs propriétaires simultanément.
